# StarUML

Coloque aquí el modelo `Clinica_Vida_Salud.mdj` y los diagramas de clases de diseño de cada caso de uso
exportados como imagen (`CU01_clases.png` … `CU14_clases.png`). En StarUML: *File → Export Diagram As → PNG*.

Las clases del diseño son las del código: `CUxxNombre` (control), `XModelo` (entidad), las vistas de
`frontend/vistas/` (interfaz) y los servicios `Disponibilidad` y `EstadoCita`.
